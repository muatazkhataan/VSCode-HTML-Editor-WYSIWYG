## التحديثات المضافة

### 1️⃣ محرر الروابط المتقدم 🔗

#### المشكلة القديمة
كان المحرر يستخدم `prompt()` بسيط لإضافة الروابط:
- واجهة قديمة وغير احترافية
- لا يمكن تحرير الروابط الموجودة
- لا يمكن تخصيص target أو title
- تجربة مستخدم سيئة

#### الحل الجديد ✅
محرر روابط متقدم واحترافي مع:
- ✅ **نافذة حوار عصرية** تتناسب مع VS Code
- ✅ **تحرير الروابط الموجودة** بالنقر عليها
- ✅ **خيارات متقدمة**: URL, نص الرابط, title, target
- ✅ **زر إزالة** للروابط الموجودة
- ✅ **اختصارات لوحة المفاتيح**: Enter (حفظ), Escape (إلغاء)
- ✅ **حالة active** في شريط الأدوات عند النقر على رابط

#### الملفات المعدلة
- `media/webview.js` (+210 أسطر)
- `media/styles.css` (+120 أسطر)

### 2️⃣ منع فتح الروابط في المحرر 🚫

#### المشكلة
عند النقر على رابط لتحريره، كان يفتح في المتصفح ويشتت المستخدم.

#### الحل ✅
إضافة معالج حدث `click` يمنع السلوك الافتراضي للروابط:

```javascript
editor.addEventListener('click', (e) => {
    let target = e.target;
    while (target && target !== editor) {
        if (target.tagName === 'A') {
            e.preventDefault();
            return;
        }
        target = target.parentElement;
    }
});
```

**النتيجة**: الآن يمكن النقر على الروابط بأمان للتحرير دون فتحها!

### 3️⃣ وضع التمييز (Highlight Mode) ✨

#### الفكرة
زر في شريط الأدوات يفعل تنسيقات مرئية لجميع العناصر لرؤية هيكل المستند بوضوح.

#### المميزات ✅
- ✅ **عناوين بألوان مختلفة** (H1-H6) مع تاج جانبي
- ✅ **روابط مع أيقونة 🔗** وخلفية صفراء
- ✅ **جداول بحدود منقطة** (إذا لم تكن محددة)
- ✅ **فقرات وقوائم بخلفية خفيفة**
- ✅ **عناصر div بخلفية حمراء خفيفة**
- ✅ **تأثيرات hover** على جميع العناصر
- ✅ **تأثيرات انتقالية سلسة**

#### الاستخدام
1. انقر زر **التمييز** 🖍️ (أول زر في الأدوات)
2. شاهد جميع العناصر مميزة
3. انقر مرة أخرى للإلغاء

#### الملفات المعدلة
- `media/webview.js` (+20 سطر)
- `media/styles.css` (+220 سطر)

#### الوثائق
- `test-highlight-mode.html` - ملف اختبار شامل
- `_md/وضع_التمييز.md` - وثائق كاملة
