# ميزة التبديل التلقائي بين ملفات HTML 🔄

## نظرة عامة

الآن المحرر المرئي يتحدث **تلقائياً** عندما تنتقل من ملف HTML إلى ملف HTML آخر! لا حاجة لإغلاق وإعادة فتح المحرر.

---

## كيف يعمل؟ 🎯

### قبل التحديث ❌

```
1. افتح file1.html
2. افتح المحرر المرئي
3. انتقل إلى file2.html
4. المحرر لا يزال يعرض file1.html ⚠️
5. يجب إغلاق وإعادة فتح المحرر
```

### بعد التحديث ✅

```
1. افتح file1.html
2. افتح المحرر المرئي
3. انتقل إلى file2.html
4. المحرر يتحدث تلقائياً ويعرض file2.html! 🎉
5. جميع الأنماط والمحتوى يتحدث تلقائياً
```

---

## جربه الآن! 🚀

### الخطوات:

1. **افتح المحرر المرئي** على أي ملف HTML:
   ```
   Ctrl+Shift+P → "WYSIWYG: Open Visual Editor"
   ```

2. **انتقل إلى ملف HTML آخر** في المحرر:
   - استخدم `Ctrl+Tab` للتبديل بين الملفات
   - أو انقر على ملف آخر في Explorer
   - أو افتح ملف جديد

3. **شاهد المعجزة!** ✨
   - المحرر المرئي يتحدث تلقائياً
   - يعرض محتوى الملف الجديد
   - يطبق أنماط CSS الخاصة بالملف الجديد
   - كل شيء يعمل تلقائياً!

---

## الأمثلة العملية 📝

### مثال 1: التبديل بين صفحات مشروع

```
مشروعك:
├── index.html      ← افتح المحرر هنا
├── about.html      ← انتقل إلى هنا
└── contact.html    ← ثم إلى هنا
```

عند كل انتقال، المحرر يتحدث تلقائياً! 🎯

### مثال 2: التبديل بين ملفات الاختبار

```
افتح المحرر على: test.html
انتقل إلى: test-with-external-css.html
انتقل إلى: test-with-bootstrap.html
```

كل ملف له أنماطه الخاصة، والمحرر يعرضها جميعاً! 🎨

---

## ما الذي يتحدث؟ 🔄

عند التبديل إلى ملف HTML جديد:

✅ **المحتوى** - يتحدث فوراً  
✅ **ملفات CSS المحلية** - يتم قراءتها وتطبيقها  
✅ **روابط CSS الخارجية** - يتم تحميلها  
✅ **الأنماط الداخلية** - يتم تطبيقها  
✅ **عنوان المحرر** - يبقى كما هو (يمكن تحديثه لاحقاً)

## التفاصيل التقنية 🔧

### الكود المضاف

```typescript
// الاستماع لتغيير الملف النشط
context.subscriptions.push(
    vscode.window.onDidChangeActiveTextEditor((editor) => {
        // التحقق من وجود محرر مفتوح ومحرر مرئي نشط
        if (!currentPanel || !editor) {
            return;
        }

        const document = editor.document;
        
        // التحقق من أن الملف الجديد هو HTML
        if (document.languageId !== 'html') {
            return;
        }

        // تحديث المستند الحالي
        currentDocument = document;
        
        console.log('📄 تم التبديل إلى ملف HTML جديد:', document.fileName);
        
        // تحديث محتوى الـ Webview بالكامل مع CSS الجديد
        currentPanel.webview.html = getWebviewContent(currentPanel.webview, context, document);
        
        // إرسال المحتوى الجديد
        setTimeout(() => {
            if (currentPanel && currentDocument) {
                sendInitMessage(currentPanel.webview, currentDocument);
            }
        }, 500);
    })
);
```

### كيف يعمل؟

1. **Event Listener**: يستمع لـ `onDidChangeActiveTextEditor`
2. **التحقق**: يتأكد من أن الملف الجديد هو HTML
3. **تحديث الـ HTML**: يعيد بناء الـ Webview بـ CSS الجديد
4. **إرسال المحتوى**: يرسل محتوى الملف الجديد
5. **التزامن**: يبدأ التزامن ثنائي الاتجاه مع الملف الجديد

### الأداء

- **الوقت**: ~500ms للتبديل الكامل
- **التأثير**: لا يؤثر على أداء VS Code
- **الذاكرة**: تأثير ضئيل جداً

## حالات خاصة 🎯

### ما يحدث عند الانتقال إلى ملف غير HTML؟

❌ المحرر لا يتحدث (يبقى على الملف السابق)  
✅ هذا متعمد - المحرر يعمل فقط مع ملفات HTML

### ما يحدث إذا أغلقت المحرر المرئي؟

✅ Event Listener يتوقف تلقائياً  
✅ لا توجد memory leaks

### ما يحدث إذا فتحت أكثر من محرر مرئي؟

✅ يتم إغلاق المحرر القديم تلقائياً  
✅ المحرر الجديد يعمل بشكل صحيح

## استكشاف الأخطاء 🔍

### المشكلة: المحرر لا يتحدث

**الحلول:**
1. تأكد من أن الملف الجديد هو `.html`
2. تحقق من Console (`Help > Toggle Developer Tools`)
3. أعد تحميل النافذة (`Ctrl+R`)

### المشكلة: التحديث بطيء

**الحلول:**
1. هذا طبيعي - الـ 500ms مقصودة للسماح بتحميل CSS
2. إذا كانت ملفات CSS كبيرة جداً، قد يستغرق وقتاً أطول
3. يمكن تقليل المهلة في الكود إذا لزم الأمر
