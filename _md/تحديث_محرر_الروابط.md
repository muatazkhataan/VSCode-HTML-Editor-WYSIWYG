# تحديث: محرر الروابط المتقدم ✨

## التغييرات

تم استبدال نافذة `prompt()` البسيطة بمحرر روابط متقدم واحترافي.

## قبل وبعد

### قبل ❌
```javascript
case 'createLink':
    const url = prompt('أدخل الرابط:', 'https://');
    if (url) document.execCommand('createLink', false, url);
    break;
```

### بعد ✅
```javascript
case 'createLink':
    execCreateLinkCommand();
    break;
```

## المميزات الجديدة 🎯

### 1. نافذة حوار احترافية
- تصميم يتناسب مع VS Code
- حقول منظمة وواضحة

### 2. خيارات متقدمة
- ✅ عنوان الرابط (URL)
- ✅ نص الرابط (قابل للتعديل)
- ✅ عنوان tooltip (title)
- ✅ فتح في نافذة جديدة/نفس النافذة (target)

### 3. تحرير الروابط الموجودة
- النقر على رابط موجود يفتح المحرر
- جميع القيم تظهر تلقائياً

### 4. إزالة الروابط
- زر أحمر لإزالة الرابط
- يحتفظ بالنص فقط

### 5. اختصارات لوحة المفاتيح
- **Enter**: حفظ
- **Escape**: إلغاء

### 6. حالة نشطة
- زر الرابط يظهر بحالة active عندما يكون المؤشر على رابط

## سيناريوهات الاستخدام 📖

### إضافة رابط جديد
1. حدد النص
2. انقر 🔗
3. أدخل البيانات
4. اضغط Enter أو "حفظ"

### تحرير رابط موجود
1. ضع المؤشر على الرابط
2. انقر 🔗 (سيظهر active)
3. عدّل ما تريد
4. احفظ

### إزالة رابط
1. ضع المؤشر على الرابط
2. انقر 🔗
3. اضغط "إزالة"
