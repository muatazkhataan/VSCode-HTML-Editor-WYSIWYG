# أيقونة المحرر المرئي في شريط العناوين 🎯

## الميزة الجديدة ✨

تم إضافة **أيقونة سريعة** في شريط عنوان المحرر (بجانب التابات) لفتح المحرر المرئي بنقرة واحدة!

---

## كيف تبدو؟ 👀

```
┌─────────────────────────────────────────────┐
│ test.html  ×  |  test2.html  ×  |  📋 ⚡ 👁️ │  ← هنا!
├─────────────────────────────────────────────┤
│ <html>                                      │
│   <body>                                    │
│     ...                                     │
```

**الأيقونة:** 👁️ (Preview/Eye icon)

---

## كيف تستخدمها؟ 🚀

### الطريقة 1: النقر المباشر (الأسرع!)

```
1. افتح أي ملف HTML
2. انظر لشريط العنوان (فوق المحرر)
3. انقر على أيقونة 👁️ (Preview)
4. المحرر المرئي يفتح مباشرة! ✨
```

### الطريقة 2: الأمر (كما كان)

```
Ctrl+Shift+P → "WYSIWYG: Open HTML Visual Editor"
```

---

## المزايا 🌟

### 1. سرعة الوصول ⚡
- نقرة واحدة فقط
- لا حاجة لكتابة الأمر
- أسرع بكثير من `Ctrl+Shift+P`

### 2. ذكاء في العرض 🧠
- **يظهر فقط** مع ملفات HTML
- **لا يظهر** مع ملفات JS، CSS، JSON، إلخ
- يحافظ على نظافة الواجهة

### 3. موقع مثالي 📍
- في شريط العنوان
- بجانب أيقونات Split Editor
- سهل الوصول ومألوف

---

## التفاصيل التقنية 🔧

### في package.json:

```json
"commands": [
  {
    "command": "wysiwyg.open",
    "title": "WYSIWYG: Open HTML Visual Editor",
    "icon": "$(preview)"  ← أيقونة معاينة من VS Code
  }
],
"menus": {
  "editor/title": [
    {
      "command": "wysiwyg.open",
      "when": "resourceLangId == html",  ← يظهر فقط مع HTML
      "group": "navigation"              ← في المجموعة الرئيسية
    }
  ]
}
```

### شرح الإعدادات:

| الإعداد | الوظيفة |
|---------|---------|
| `icon: "$(preview)"` | أيقونة معاينة من VS Code Codicons |
| `editor/title` | موقع الأيقونة في شريط العنوان |
| `when: resourceLangId == html` | شرط العرض (فقط HTML) |
| `group: navigation` | المجموعة (مع أيقونات Split Editor) |

---

## الأيقونات المتاحة 🎨

يمكنك تغيير الأيقونة إلى أي رمز من VS Code Codicons:

| الكود | الأيقونة | الوصف |
|------|----------|-------|
| `$(preview)` | 👁️ | معاينة (الافتراضي) |
| `$(edit)` | ✏️ | تحرير |
| `$(eye)` | 👁️ | عين |
| `$(book)` | 📖 | كتاب |
| `$(symbol-color)` | 🎨 | لون |
| `$(code)` | 💻 | كود |

### كيف تغيّر الأيقونة:

في `package.json`:
```json
"icon": "$(edit)"  // أو أي رمز آخر
```

## الاختبار 🧪

### الخطوة 1: أعد تحميل النافذة
```
Ctrl+Shift+P → "Developer: Reload Window"
```

### الخطوة 2: افتح ملف HTML
```
افتح test.html أو أي ملف HTML آخر
```

### الخطوة 3: ابحث عن الأيقونة
```
انظر لشريط العنوان (فوق المحرر مباشرة)
يجب أن ترى أيقونة 👁️ (Preview)
```

### الخطوة 4: جرّبها!
```
انقر على الأيقونة
المحرر المرئي يفتح مباشرة! ✨
```

|---------|---------|---------|
| **الأيقونة** ✨ | 1 نقرة | ⚡⚡⚡ سريع جداً |
| الأمر | Ctrl+Shift+P + كتابة + Enter | ⚡ عادي |
| القائمة | Right-click + اختيار | ⚡⚡ متوسط |

## أين تظهر الأيقونة؟ 📍

### ✅ يظهر في:
- ملفات `.html`
- ملفات `.htm`
- أي ملف مُعرّف كـ HTML

### ❌ لا يظهر في:
- ملفات JavaScript (`.js`)
- ملفات CSS (`.css`)
- ملفات JSON (`.json`)
- أي ملف غير HTML

---

## نصائح الاستخدام 💡

### نصيحة 1: الوصول السريع
```
افتح HTML → انقر الأيقونة → ابدأ التحرير
أسرع طريقة للوصول للمحرر المرئي!
```

### نصيحة 2: تعدد الملفات
```
إذا كان لديك عدة ملفات HTML مفتوحة:
- كل تاب له أيقونته الخاصة
- انقر الأيقونة في التاب الذي تريده
```

### نصيحة 3: Split View
```
يمكنك:
1. فتح HTML في تاب
2. نقر الأيقونة لفتح المحرر المرئي
3. المحرر يفتح بجانب المحرر النصي ✨
```

## استكشاف الأخطاء 🔍

### المشكلة: الأيقونة لا تظهر

**الحلول:**
1. تأكد من أنك فتحت ملف `.html`
2. أعد تحميل النافذة: `Ctrl+Shift+P` → `Reload Window`
3. تأكد من تثبيت الإضافة بشكل صحيح

### المشكلة: الأيقونة غير واضحة

**الحل:**
يمكنك تغيير الأيقونة في `package.json`:
```json
"icon": "$(edit)"  // أيقونة قلم أوضح
```

### المشكلة: الأيقونة في مكان غير مناسب

**الحل:**
يمكنك تغيير المجموعة:
```json
"group": "1_open"  // في بداية القائمة
```
