## التاريخ: 21 أكتوبر 2025

## 🎯 الهدف من التحديث

تطوير المحرر ليدعم **قراءة وتطبيق ملفات CSS الخارجية** المرتبطة بملفات HTML، مما يجعل المعاينة أكثر دقة واحترافية.

---

## ✨ الميزات الجديدة

### 1. دعم ملفات CSS المحلية

```html
<link rel="stylesheet" href="styles.css">
<link rel="stylesheet" href="css/theme.css">
<link rel="stylesheet" href="../shared/common.css">
```

- يقرأ المحرر محتوى الملفات من القرص
- يطبق الأنماط في المعاينة المرئية
- دعم المسارات النسبية (relative paths)

### 2. دعم مكتبات CSS الخارجية (CDN)

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css">
<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.4.0/css/all.min.css">
```

- Bootstrap
- Font Awesome
- Google Fonts
- Tailwind CSS
- أي مكتبة CSS أخرى

### 3. تحويل ذكي للأنماط

الأنماط المطبقة على `body` يتم تحويلها تلقائياً لـ `#editor`:

```css
/* في الملف الأصلي */
body { background: #f5f5f5; }
body > h1 { color: red; }

/* في المحرر */
#editor { background: #f5f5f5; }
#editor > h1 { color: red; }
```

### 4. دمج الأنماط

يمكن استخدام الأنماط الخارجية والداخلية معاً:

```html
<head>
    <!-- خارجي -->
    <link rel="stylesheet" href="main.css">
    
    <!-- داخلي -->
    <style>
        .special { color: blue; }
    </style>
</head>
```

#### 3. تحويل الأنماط

```typescript
const convertedCss = cssContent
    .replace(/\bbody\s*\{/g, '#editor {')
    .replace(/\bbody\s+/g, '#editor ')
    .replace(/\bbody\s*>/g, '#editor >');
```
