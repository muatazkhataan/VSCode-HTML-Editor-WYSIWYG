# وضع التمييز (Highlight Mode) ✨

## نظرة عامة

ميزة جديدة تضيف تنسيقات مرئية لجميع عناصر HTML في المحرر لمساعدتك على:
- رؤية هيكل المستند بوضوح
- تمييز العناصر المختلفة بألوان
- تحديد العناصر بسهولة أثناء التحرير
- فهم التسلسل الهرمي للمحتوى

## كيفية الاستخدام

### تفعيل وضع التمييز

1. افتح ملف HTML في المحرر المرئي
2. انقر على زر **التمييز** 🖍️ (أول زر في شريط الأدوات)
3. سترى جميع العناصر مميزة بألوان وتأثيرات مرئية

### إلغاء وضع التمييز

1. انقر مرة أخرى على زر **التمييز** 🖍️
2. ستختفي جميع التنسيقات المرئية
3. الزر يعمل كمفتاح تبديل (Toggle)

## التنسيقات المرئية

### 1. العناوين (H1-H6)

كل عنوان له:
- **لون خلفية مميز** حسب المستوى:
  - H1: أزرق فاتح
  - H2: أخضر مائل للأزرق
  - H3: أخضر
  - H4: أخضر فاتح
  - H5: أصفر مخضر
  - H6: أصفر

- **تاج جانبي** يعرض مستوى العنوان (H1, H2, إلخ)
- **تأثير hover**: الخلفية تصبح صفراء خفيفة والتاج يتمدد

#### مثال بصري:

```
┌─────────────────────────────────┐
│  عنوان من المستوى الأول      │ H1 │
└─────────────────────────────────┘
```

### 2. الروابط (Links)

الروابط تظهر مع:
- **خلفية صفراء** فاتحة
- **أيقونة 🔗** على الجانب
- **تأثير hover**: الخلفية تصبح أغمق
- **لون نص** بني داكن

#### مثال بصري:

```
┌──────────────┐
│ نص الرابط   │ 🔗 │
└──────────────┘
```

### 3. الجداول (Tables)

الجداول تحصل على:
- **حدود منقطة** رمادية (إذا لم تكن محددة مسبقاً)
- **تأثير hover على الخلايا**: خلفية زرقاء خفيفة
- **تأثير hover على الجدول**: حد أزرق
- **حد أدنى للعرض والارتفاع** للخلايا

### 4. الفقرات وعناصر القوائم (P, LI)

- **خلفية صفراء** خفيفة جداً (شبه شفافة)
- **حواف مستديرة**
- **تأثير hover**: خلفية أوضح + ظل خفيف

### 5. عناصر DIV

- **خلفية حمراء** خفيفة جداً (للتمييز عن الفقرات)
- **حواف مستديرة**
- **تأثير hover**: خلفية أوضح + ظل

## المميزات التقنية

### 1. لا يؤثر على HTML النهائي
- جميع التنسيقات مؤقتة فقط في المحرر
- عند الحفظ، يتم حفظ HTML الأصلي بدون التنسيقات
- التنسيقات تُطبق عبر CSS فقط

### 2. تفعيل/إلغاء فوري
- بنقرة واحدة تظهر/تختفي جميع التنسيقات
- لا حاجة لإعادة تحميل
- الحالة تُحفظ في جلسة التحرير

### 3. حالة نشطة في شريط الأدوات
- الزر يظهر بحالة **active** (أزرق) عندما يكون التمييز مفعلاً
- يعطي تغذية بصرية واضحة للحالة الحالية

### 4. تأثيرات انتقالية سلسة
- جميع التأثيرات تحدث بسلاسة (transition)
- تجربة مستخدم احترافية

## التفاصيل التقنية

### الآلية

عند تفعيل التمييز:
```javascript
editor.classList.add('custom-editor');
```

عند الإلغاء:
```javascript
editor.classList.remove('custom-editor');
```

### CSS Selectors

جميع التنسيقات تستخدم selector `.custom-editor`:

```css
.custom-editor h1 {
    background-color: rgba(109, 207, 246, 0.1);
    /* ... */
}

.custom-editor a {
    background-color: rgba(255, 193, 7, 0.25);
    /* ... */
}

/* إلخ... */
```

### الملفات المعدلة

#### 1. `media/styles.css`
- إضافة ~220 سطر من CSS للتنسيقات
- جميع التنسيقات تحت `.custom-editor`

#### 2. `media/webview.js`
- إضافة دالة `toggleHighlightMode()`
- إضافة زر في شريط الأدوات
- تحديث `updateToolbarState()` لإظهار الحالة

## حالات الاستخدام

### 1. تحرير مستندات معقدة
عندما تحرر مستند به عناصر كثيرة، التمييز يساعدك على:
- معرفة نوع كل عنصر فوراً
- تتبع هيكل المستند
- تحديد الروابط بسهولة

### 2. تصحيح الأخطاء
- رؤية الجداول بدون حدود
- تحديد عناصر div غير المرغوبة
- التأكد من مستويات العناوين

### 3. التدريب والتعليم
- تعليم HTML للمبتدئين
- إظهار الفرق بين العناصر
- فهم التسلسل الهرمي

## الاختبار

استخدم ملف `test-highlight-mode.html`:

```bash
# في VS Code
1. افتح test-highlight-mode.html
2. Ctrl+Shift+P > "Open HTML Visual Editor"
3. انقر زر التمييز 🖍️
4. جرب جميع العناصر
```

الملف يحتوي على:
- ✅ جميع مستويات العناوين (H1-H6)
- ✅ روابط بخيارات مختلفة
- ✅ قوائم (نقطية ومرقمة)
- ✅ جداول (بحدود وبدون)
- ✅ فقرات وعناصر div
- ✅ محتوى مختلط

## التخصيص

يمكنك تخصيص الألوان والتنسيقات في `media/styles.css`:

### تغيير لون العناوين

```css
.custom-editor h1 {
    background-color: rgba(255, 0, 0, 0.1); /* أحمر فاتح */
}
```

### تغيير لون الروابط

```css
.custom-editor a {
    background-color: rgba(0, 255, 0, 0.25); /* أخضر */
}
```

### تغيير أيقونة الرابط

```css
.custom-editor a::before {
    content: "⚡"; /* برق بدل 🔗 */
}
```

## المقارنة

### قبل وضع التمييز ❌
- كل شيء يبدو متشابهاً
- صعوبة تمييز العناصر
- لا يوجد مؤشر لمستويات العناوين
- الجداول بدون حدود غير مرئية

### مع وضع التمييز ✅
- كل عنصر له لون مميز
- سهولة تحديد نوع العنصر
- مؤشر واضح لمستويات العناوين
- جميع الجداول مرئية
- تأثيرات تفاعلية

## الأداء

- ✅ لا تأثير على الأداء (CSS فقط)
- ✅ تفعيل/إلغاء فوري
- ✅ لا تحميل إضافي
- ✅ يعمل مع مستندات كبيرة

## التوافق

- ✅ يعمل مع جميع عناصر HTML
- ✅ متوافق مع RTL/LTR
- ✅ لا يتعارض مع تنسيقات المستخدم
- ✅ يعمل مع الـ inline styles

## نصائح

1. **استخدم التمييز عند التحرير** وأغلقه عند المعاينة النهائية
2. **التمييز مفيد للمستندات الكبيرة** حيث يسهل التنقل
3. **جرب hover على العناصر** لرؤية التأثيرات التفاعلية
4. **الزر يعمل كـ Toggle** - نقرة واحدة للتفعيل/الإلغاء
