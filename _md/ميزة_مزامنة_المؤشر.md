# 🎯 ميزة مزامنة المؤشر

## ✨ ميزة جديدة: مزامنة موضع المؤشر

عند التحرير في المحرر المرئي، يتحرك المؤشر تلقائياً في محرر VS Code/Cursor ليظهر نفس المنطقة!

---

## 🔄 كيف تعمل؟

### 1. **عند الكتابة في المحرر المرئي:**

```
المستخدم يكتب في المحرر المرئي
    ↓
حساب موضع المؤشر النسبي في محتوى body
    ↓
إرسال الموضع إلى Extension
    ↓
Extension يحسب الموضع الفعلي في الملف
    ↓
تحريك المؤشر في محرر VS Code
    ↓
عرض المنطقة في الوسط إذا كانت خارج الشاشة
```

### 2. **عند النقر بالماوس:**

```
المستخدم ينقر في المحرر المرئي
    ↓
تحديث موضع المؤشر
    ↓
مزامنة مع محرر VS Code
    ↓
المؤشر يتحرك في الملف النصي
```

---

## 🎯 الفوائد

### 1. **سهولة التنقل:**

- تحرير مرئي في المحرر
- متابعة الكود في الملف النصي
- معرفة موضعك بالضبط

### 2. **مفيد للتعلم:**

- رؤية كيف يتحول التحرير المرئي إلى HTML
- فهم بنية HTML أثناء التحرير
- ربط المفاهيم المرئية بالكود

### 3. **سير عمل هجين:**

- تحرير سريع في الوضع المرئي
- تعديلات دقيقة في الكود
- الاثنان متزامنان تماماً

---

## 💡 مثال عملي

### السيناريو

```
1. افتح test.html في المحرر المرئي
2. انقر على العنوان "مرحباً بك"
3. 🎯 المؤشر في VS Code ينتقل إلى السطر 31:
   <h1>مرحباً بك في محرر HTML المرئي</h1>
4. ابدأ الكتابة في المحرر المرئي
5. 🎯 المؤشر يتحرك مع كل حرف تكتبه!
```

---

## ⚙️ التفاصيل التقنية

### آلية الحساب

```javascript
// في webview.js:
1. حساب عدد الأحرف قبل المؤشر في المحرر
2. إرسال هذا الرقم إلى Extension

// في extension.ts:
3. البحث عن موضع <body> في الملف
4. إضافة offset المؤشر من المحرر
5. تحويل إلى position (line, column)
6. تحريك المؤشر وعرض المنطقة
```

### API المستخدم

```typescript
// تحريك المؤشر
editor.selection = new vscode.Selection(position, position);

// عرض المنطقة
editor.revealRange(
    new vscode.Range(position, position),
    vscode.TextEditorRevealType.InCenterIfOutsideViewport
);
```

## ⚡ الأداء

### تحسينات

- ✅ Debounce: لا يرسل في كل حركة
- ✅ يرسل فقط عند keyup/mouseup
- ✅ معالجة آمنة للأخطاء
- ✅ لا يؤثر على الأداء

### استهلاك الموارد

- 📊 رسائل قليلة (فقط عند توقف الكتابة)
- 📊 حسابات بسيطة وسريعة
- 📊 لا تأثير ملحوظ على السرعة

## 🎯 حالات الاستخدام

### 1. **التحرير الهجين:**

```
- حرك المؤشر في المحرر المرئي
- راقب الكود في المحرر النصي
- عدّل الكود مباشرة عند الحاجة
```

### 2. **التعلم:**

```
- اكتب نصاً في المحرر المرئي
- راقب كيف يتحول إلى HTML
- افهم العلاقة بين المرئي والكود
```

### 3. **التصحيح:**

```
- إذا كان هناك مشكلة في التنسيق
- انقر على العنصر في المحرر المرئي
- اذهب مباشرة للكود المقابل
```
