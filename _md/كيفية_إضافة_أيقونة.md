# 🎨 كيفية إضافة أيقونة للإضافة

## 📋 المتطلبات

الأيقونة يجب أن تكون:

- **الصيغة**: PNG
- **الحجم**: 128x128 بكسل (أو أكبر، يُفضل 256x256)
- **الاسم**: `icon.png`
- **الموقع**: في جذر المشروع

---

## 🎨 الطريقة 1: إنشاء أيقونة بسيطة (موصى بها)

### الخيار A: باستخدام HTML/Canvas

1. **افتح الملف:** `create-icon.html` في المتصفح
2. **انقر على:** "تحميل الأيقونة"
3. **احفظ باسم:** `icon.png`
4. **انقل الملف** إلى جذر المشروع:

   ```bash
   mv ~/Downloads/icon.png /Users/muataz/Workspace/VSCode-HTML-Editor-WYSIWYG/
   ```

### الخيار B: باستخدام أداة أونلاين

استخدم أحد هذه المواقع:

- <https://www.canva.com> (مجاني)
- <https://www.figma.com> (مجاني)
- <https://www.photopea.com> (مجاني - شبيه Photoshop)

**المواصفات:**

- الحجم: 256x256 بكسل
- الصيغة: PNG مع شفافية
- التصميم: بسيط وواضح

### الخيار C: باستخدام Emoji

```bash
# استخدم أداة تحويل emoji إلى PNG
# أو استخدم screenshot لـ emoji كبير
```

## ⚙️ إضافة الأيقونة للمشروع

### الخطوة 1: ضع الملف في جذر المشروع

```
VSCode-HTML-Editor-WYSIWYG/
├── icon.png          ← هنا!
├── package.json
├── src/
└── ...
```

### الخطوة 2: تم بالفعل! ✅

قمت بإضافة `"icon": "icon.png"` في `package.json`

## 🚀 إعادة البناء

بعد إضافة `icon.png`:

```bash
cd /Users/muataz/Workspace/VSCode-HTML-Editor-WYSIWYG

# 1. تأكد من وجود الأيقونة
ls -lh icon.png

# 2. أعد البناء
npm run build

# 3. أنشئ الحزمة
npx @vscode/vsce package --no-dependencies

# 4. ثبّت في Cursor
# Cmd+Shift+P → Install from VSIX
```
