# إصلاح مشكلة الكتابة في الملف الخطأ 🔧

## المشكلة 🐛

عند التبديل بين ملفات HTML، كان المحرر يكتب التغييرات في **الملف الأول** الذي تم فتح المحرر منه، وليس الملف الحالي النشط.

### سيناريو المشكلة:

```
1. افتح test.html
2. افتح المحرر المرئي
3. انتقل إلى test-with-external-css.html
4. المحرر يعرض محتوى test-with-external-css.html ✅
5. عدّل المحتوى في المحرر
6. التعديلات تُكتب في test.html ❌ (الملف الخطأ!)
```

---

## السبب 🔍

### في الكود الأصلي:

```typescript
function createWebviewPanel(context: vscode.ExtensionContext, document: vscode.TextDocument) {
    // ...
    
    panel.webview.onDidReceiveMessage(
        async (message) => {
            switch (message.type) {
                case 'updateHtml':
                    // ❌ يستخدم document المحلي (الملف الأول)
                    await updateDocument(document, message.html);
                    break;
                    
                case 'saveAsset':
                    // ❌ يستخدم document المحلي
                    await saveAsset(panel.webview, document, ...);
                    break;
                    
                case 'cursorPosition':
                    // ❌ يستخدم document المحلي
                    syncCursorToDocument(document, message.offset);
                    break;
            }
        }
    );
}
```

**المشكلة:**
- `document` هو متغير محلي يتم تمريره عند إنشاء الـ Webview
- عند التبديل لملف آخر، يتم تحديث `currentDocument` فقط
- لكن message handler يستمر في استخدام `document` القديم!

## الحل ✅

### استخدام `currentDocument` بدلاً من `document`:

```typescript
panel.webview.onDidReceiveMessage(
    async (message) => {
        console.log('Extension received message:', message.type);
        
        // ✅ التحقق من وجود currentDocument
        if (!currentDocument) {
            console.error('❌ No current document available');
            return;
        }
        
        switch (message.type) {
            case 'updateHtml':
                // ✅ يستخدم currentDocument (الملف الحالي)
                console.log('Updating document:', currentDocument.fileName);
                await updateDocument(currentDocument, message.html);
                break;
                
            case 'saveAsset':
                // ✅ يستخدم currentDocument
                await saveAsset(panel.webview, currentDocument, ...);
                break;
                
            case 'cursorPosition':
                // ✅ يستخدم currentDocument
                syncCursorToDocument(currentDocument, message.offset);
                break;
        }
    }
);
```

## التغييرات المطبقة 📝

## كيف يعمل الآن 🎯

### متغيرات الحالة:

```typescript
let currentPanel: vscode.WebviewPanel | undefined;
let currentDocument: vscode.TextDocument | undefined;  // ← يتم تحديثه عند التبديل
```

### عند فتح المحرر لأول مرة:

```typescript
currentDocument = document;  // الملف الأول
```

### عند التبديل لملف آخر:

```typescript
vscode.window.onDidChangeActiveTextEditor((editor) => {
    currentDocument = editor.document;  // ← تحديث للملف الجديد
    // ...
});
```

### عند التحرير:

```typescript
case 'updateHtml':
    await updateDocument(currentDocument, message.html);  // ← يكتب في الملف الصحيح!
```

## ملاحظات مهمة ⚠️

### 1. متى يتم تحديث `currentDocument`؟

- عند فتح المحرر لأول مرة
- عند التبديل لملف HTML آخر

### 2. متى لا يتم التحديث؟

- عند التبديل لملف غير HTML (يُتجاهل)
- عند إغلاق المحرر (يصبح `undefined`)

### 3. الأمان

الكود الآن يتحقق من `currentDocument` قبل كل عملية، مما يمنع أي أخطاء.
