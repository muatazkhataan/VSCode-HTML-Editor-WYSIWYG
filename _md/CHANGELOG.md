# سجل التغييرات

## [0.0.2] - 2025-10-21

### التحديثات الجديدة

#### الميزات المضافة

- ✨ **دعم ملفات CSS الخارجية**: المحرر الآن يقرأ تلقائياً ملفات CSS المرتبطة بـ `<link>` ويطبقها في المعاينة
- ✨ **دعم مكتبات CSS من CDN**: يمكن استخدام Bootstrap، Font Awesome، وغيرها من المكتبات الخارجية
- ✨ **تحويل ذكي للأنماط**: تحويل تلقائي من `body` إلى `#editor` لضمان عمل الأنماط في المحرر
- ✨ **دمج الأنماط**: دعم استخدام الأنماط الداخلية `<style>` والخارجية معاً
- ✨ **معالجة الأخطاء**: رسائل واضحة في Console عند عدم وجود ملفات CSS أو فشل القراءة
- 🔄 **التبديل التلقائي بين الملفات**: المحرر يتحدث تلقائياً عند الانتقال من ملف HTML إلى آخر!

#### التحسينات التقنية

- 🔧 تحديث `getWebviewContent()` لقراءة ملفات CSS المحلية من القرص
- 🔧 استخدام `matchAll()` للبحث عن جميع روابط CSS في HTML
- 🔧 إضافة `onDidChangeActiveTextEditor` listener للتبديل التلقائي بين الملفات
- 🔧 تحديث تلقائي للـ Webview HTML عند تغيير الملف النشط
- 🔧 تحديث Content Security Policy لدعم الموارد الخارجية:
  - `img-src`: دعم https
  - `script-src`: دعم https
  - `style-src`: دعم https و unsafe-inline
  - `font-src`: دعم https و data:
  - `connect-src`: دعم https
- 🔧 إضافة `console.log` لتتبع تحميل ملفات CSS وتبديل الملفات

#### الملفات الجديدة

- 📄 `test-styles.css` - ملف CSS تجريبي مع تصميم جميل
- 📄 `test-with-external-css.html` - مثال HTML يستخدم ملف CSS خارجي
- 📄 `test-with-bootstrap.html` - مثال متقدم باستخدام Bootstrap و Font Awesome
- 📄 `دعم_ملفات_CSS_الخارجية.md` - توثيق شامل للميزة الجديدة
- 📄 `CSS_SUPPORT_QUICK_GUIDE.md` - دليل سريع للاستخدام
- 📄 `ميزة_التبديل_التلقائي_بين_الملفات.md` - توثيق ميزة التبديل التلقائي

#### كيفية الاستخدام

```html
<!-- ملفات CSS محلية -->
<link rel="stylesheet" href="styles.css">

<!-- مكتبات خارجية -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css">
```

## [0.0.1] - 2025-10-20

### الإصدار الأولي

#### الميزات المضافة

- ✨ محرر HTML مرئي باستخدام CKEditor 4
- ✨ تزامن ثنائي الاتجاه بين المحرر والملف
- ✨ دعم كامل للغة العربية والكتابة من اليمين لليسار (RTL)
- ✨ رفع ولصق الصور تلقائيًا مع حفظها في مجلد `assets/`
- ✨ Content Security Policy (CSP) صارم
- ✨ يعمل بدون اتصال بالإنترنت (CKEditor محلي)
- ✨ Debounce ذكي لتجنب التحديثات المتكررة

#### التقنيات المستخدمة

- VS Code Extension API
- CKEditor 4.22.1 (Standard Package)
- TypeScript 5.6.3
- esbuild للبناء
- Webview API مع Nonce-based CSP

- [x] تزامن من الملف إلى المحرر
- [x] حفظ الصور في مجلد assets/ مع مسارات نسبية
- [x] يعمل بدون إنترنت
