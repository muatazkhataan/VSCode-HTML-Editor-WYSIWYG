       دليل بناء حزمة VSIX لامتداد HTML WYSIWYG Editor
═══════════════════════════════════════════════════════════════

📦 تم إنشاء برامج نصية تلقائية لبناء المشروع بسهولة!

═══════════════════════════════════════════════════════════════
  الطريقة الأولى: استخدام PowerShell (موصى به)
═══════════════════════════════════════════════════════════════

1. افتح PowerShell في مجلد المشروع
2. نفّذ الأمر التالي:

   .\build-vsix.ps1

✅ المميزات:
   • تحقق تلقائي من جميع المتطلبات
   • تثبيت تلقائي للأدوات المفقودة
   • رسائل ملونة واضحة
   • عرض تفصيلي للنتائج

═══════════════════════════════════════════════════════════════
  الطريقة الثانية: استخدام Batch File
═══════════════════════════════════════════════════════════════

1. افتح Command Prompt في مجلد المشروع
2. نفّذ الأمر التالي:

   build-vsix.bat

ملاحظة: يُفضل تشغيله من Command Prompt وليس PowerShell

═══════════════════════════════════════════════════════════════
  الطريقة الثالثة: البناء اليدوي
═══════════════════════════════════════════════════════════════

1. تثبيت التبعيات:
   npm install

2. بناء المشروع:
   npm run build

3. تثبيت vsce (إذا لم يكن مثبتاً):
   npm install -g @vscode/vsce

4. بناء حزمة VSIX:
   vsce package

═══════════════════════════════════════════════════════════════
  تثبيت الامتداد
═══════════════════════════════════════════════════════════════

▶ في VS Code:
  code --install-extension vscode-html-wysiwyg-0.0.1.vsix

▶ في Cursor:
  cursor --install-extension vscode-html-wysiwyg-0.0.1.vsix

▶ عبر الواجهة الرسومية:
  1. Extensions (Ctrl+Shift+X)
  2. انقر "..." في الأعلى
  3. اختر "Install from VSIX..."
  4. حدد الملف
