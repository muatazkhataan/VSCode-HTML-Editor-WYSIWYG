🎨 محرر HTML مع دعم CSS الخارجي

مرحباً بك في النسخة المطورة!

هذا المحرر الآن يدعم ملفات CSS الخارجية! يمكنك ربط ملفات الأنماط باستخدام <link> وسيتم تطبيقها تلقائياً في المعاينة.

الميزات الجديدة:

  • ✅ قراءة وتطبيق ملفات CSS الخارجية المحلية
  • ✅ دعم ملفات CSS الخارجية عبر الإنترنت (http/https)
  • ✅ دمج الأنماط الداخلية (<style>) والخارجية
  • ✅ تحويل تلقائي للأنماط من body إلى #editor
  • ✅ معالجة الأخطاء عند عدم وجود الملفات

كيفية الاستخدام:

ببساطة أضف ملف CSS في نفس المجلد أو مجلد فرعي، ثم أضف العلامة التالية في <head>:

<link rel="stylesheet" href="test-styles.css">

ملاحظة مهمة: الأنماط المطبقة على body في ملف CSS الخارجي سيتم تحويلها تلقائياً لتطبيقها على منطقة المحرر.

💡 نصيحة: يمكنك أيضاً استخدام مكتبات CSS شهيرة مثل Bootstrap أو Tailwind من خلال الروابط الخارجية!
